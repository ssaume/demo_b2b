# Demo B2B 企業採購與供應協作平台 v1.0.3.3

部署：GitHub Pages＋Google Apps Script＋Google Sheets。完整升級流程見 docs/DEPLOYMENT.md。

## 本版三項更新

1. 自動同步由 30 秒改為 60 秒。頁面隱藏、交易操作或對話框開啟時暫停；一次自動同步未完成前不重複發出。手動同步、送單及供應回饋仍立即執行。
2. 管理帳號上方新增「Demo 資料」，可清除交易或帶入示範。操作前必須勾選確認，正式模式會修改同一 Sheets 的共用資料，本機預覽只修改目前瀏覽器。清除後保留必要主檔，採購可從空白訂單開始，供應端可備料、生產、入庫、部分／全數出貨或中止。帶入 Demo 覆蓋人工交易並還原示範主檔與六種狀態。
3. 點擊資源名稱可展開耗用單據、需求／訂單、產品／料號、狀態、交期及耗用量。材料用件、產線用小時、倉儲用庫位；「供應網路」定位該訂單產品。期間與資源篩選一致，包含逾期未完成，不列已出貨／中止。每筆由後端驗證目前負責／有效代理權限，全體彙總不會開放其他供應組明細。

## 模型範圍與計算

預設 BOM、Routing、材料庫存、Open PO 與資源能力是示範資料，可在 PlanMasters／ResourceMasters 更新；新需求才套用新 BOM／Routing，既有網路快照保留。資源能力與庫存是查詢當下的主檔。

網路節點單據為本平台的供應計畫識別，不等於已在 ERP 正式過帳。庫存與 Open PO 尚未自動同步 ERP、扣帳或做庫存分配。節點進度優先使用回報實績；未回報時顯示依單據階段推估，兩者有標示。

CPM 計算相依網路的最長歷時路徑；總體作業工時為所有節點作業工時相加。歷時含材料等待與工作站能力換算，可與作業工時不同。每日 8 小時、週一至週五，未扣國定假日。尚非跨訂單有限產能排程，不保證所有需求同時能準時交付。情境產能會調整本產品相關資源可用工時；材料前置期可留空沿用各材料主檔。
